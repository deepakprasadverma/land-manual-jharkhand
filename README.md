# Land Manual of Jharkhand (झारखंड में भूमि खरीद-बिक्री का पूर्ण मार्गदर्शक)

Official landing page for the authoritative book release **"Land Manual of Jharkhand"** by **Salendra Kumar Verma**.

## 📖 Overview
A comprehensive legal and practical manual on land acquisition, title verification, registry, mutation (Dakhil-Kharij), and tenancy laws in Jharkhand including detailed coverage of:
- **Chota Nagpur Tenancy (CNT) Act 1908**
- **Santhal Parganas Tenancy (SPT) Act 1949**
- **Khatiyan, Jamabandi & Register-II Verification**
- **Jharbhoomi Workflow & High Court Precedents**

## 🚀 Live Demo & Deployment
This project is built with **HTML5** and **Tailwind CSS (via CDN)**. It is ready for one-click hosting on **GitHub Pages**, Vercel, or Netlify.

### Deploying to GitHub Pages:
1. Create a repository on GitHub (e.g., `land-manual-jharkhand`).
2. Push this codebase:
   ```bash
   git remote add origin https://github.com/<YOUR-USERNAME>/land-manual-jharkhand.git
   git branch -M main
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Branch**, select `main` and root `/`.
   - Click **Save**. Your site will be live at `https://<YOUR-USERNAME>.github.io/land-manual-jharkhand/`!
